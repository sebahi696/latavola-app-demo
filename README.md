# La Tavola Beirut - app demo (GitHub Pages)

Static demo of the ordering app (web build of the Expo app) + operator panel, with an in-browser simulated backend.
Built from `Sebahi.services/orderapp` with `orderapp/demo/build-demo.sh`. Nothing here is production.

- Demo: https://sebahi696.github.io/latavola-app-demo/
- Customer app: `/app/` - sign in with any phone, OTP `123456`, coupon `WELCOME10`
- Operator: `/operator/` - restaurant `latavola`, any email, password `demo`
